همیار معلم 🎓

دستیار هوشمند معلمان دوره ابتدایی برای طراحی، تولید و مدیریت محتوای آموزشی.

امکانات

- ساخت بسته کامل تدریس
- طراحی طرح درس
- تولید فعالیت‌های آموزشی
- طراحی بازی آموزشی
- تولید کاربرگ
- کاربرگ سطح‌بندی‌شده برای دانش‌آموزان ضعیف، متوسط و قوی
- طراحی تکلیف
- ارزشیابی تکوینی و توصیفی
- پیشنهاد فعالیت‌های تربیتی و مهارت‌های زندگی
- مدیریت کلاس
- برنامه‌ریزی هفتگی
- حالت تدریس اضطراری
- تاریخچه تولید محتوا
- جلوگیری از تکرار فعالیت‌ها
- قابلیت چاپ محتوای آموزشی
- طراحی مناسب برای زبان فارسی و رابط کاربری RTL

راه‌اندازی محلی

ابتدا وابستگی‌ها را نصب کنید:

npm install

سپس فایل ".env" را ایجاد کنید:

OPENAI_API_KEY=YOUR_API_KEY
OPENAI_MODEL=gpt-5
PORT=3000

سپس سرور را اجرا کنید:

npm start

برای حالت توسعه:

npm run dev

بعد مرورگر را باز کنید و وارد آدرس زیر شوید:

http://localhost:3000

امنیت

کلید API نباید داخل "public/index.html"، کد سمت مرورگر یا GitHub قرار بگیرد.

کلید واقعی باید فقط به‌عنوان Environment Variable روی سرور تنظیم شود.

API

Health Check

GET /api/health

برای بررسی وضعیت سرور استفاده می‌شود.

Generate

POST /api/generate

برای تولید محتوای آموزشی با هوش مصنوعی استفاده می‌شود.

نمونه داده:

{
  "grade": "سوم",
  "subject": "ریاضی",
  "topic": "ضرب",
  "contentType": "worksheet",
  "studentLevel": "متوسط",
  "template": "auto",
  "differentiation": true,
  "visualDesign": true,
  "avoidRepetition": true
}

هدف پروژه

همیار معلم قرار است یک ابزار واقعی و کاربردی برای معلمان ابتدایی باشد؛ نه صرفاً یک متن‌ساز.

سیستم در مراحل بعدی می‌تواند به موتور تولید محتوای آموزشی، طراحی کاربرگ، برنامه‌ریزی روزانه، مدیریت دانش‌آموزان و تولید خروجی‌های قابل چاپ توسعه پیدا کند.
